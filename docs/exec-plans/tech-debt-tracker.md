# Technical debt tracker

This tracker is retired. Introspection now dogfoods its own tech-debt records under `docs/records/tech-debt/`.

Use these commands instead:

- `introspection prime --type tech-debt` to review active tech-debt context.
- `introspection check` to validate the committed records.
- `introspection record create --type tech-debt ...` for new accepted deferrals.

Historical TD-001 through TD-014 were migrated during WI-17. TD-016 was a v1 packaging cleanup item and was resolved before adoption, so this file is no longer an active tracker.
