# introspection

`introspection` is a planned TypeScript and Effect CLI for governed markdown records. The v1 scope is a typed record substrate, deterministic checks, and an agent-friendly `prime` surface.

The current repo state is WI-01 scaffold only. Domain schemas, record types, importers, and the backpressure adoption are intentionally deferred to later work items in `docs/exec-plans/active/introspection-v1-bootstrap-2026-06-10.md`.
