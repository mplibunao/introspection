# introspection

`introspection` is a TypeScript and Effect CLI project for governed markdown records. The v1 scope is a typed record substrate, deterministic checks, and an agent-friendly `prime` surface.

The current repo state includes the WI-02 schema and layout contracts: base record, tech-debt, config, vocabulary, and export manifest schemas, plus the documented `.introspection/` and records-root source-of-truth layout. The record engine, CLI commands, importers, and backpressure adoption remain future work items in `docs/exec-plans/active/introspection-v1-bootstrap-2026-06-10.md`.
