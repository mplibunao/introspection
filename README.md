# introspection

`introspection` is a TypeScript and Effect CLI project for governed markdown records. The v1 scope is a typed record substrate, deterministic checks, disposable exports, and an agent-friendly `prime` surface.

The package is CLI-only for v1. The `introspection` bin prefers a compiled platform package and falls back to the bundled JS CLI on host Bun. See `docs/adoption.md` for the local dogfood path and publishing constraints.
